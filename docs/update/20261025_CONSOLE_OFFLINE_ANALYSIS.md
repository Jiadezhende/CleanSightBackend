# 控制台第 4 批：工作台接入离线分析与离线违规，新增「分析作业」页

> **变更状态**：生效中（2026-10-25）
> **知识库**：待沉淀

## 概述

回放工作台新增「离线分析」面板与分割段 / 逐帧概率两条泳道，离线违规并进事件泳道与事件面板；面板可运行 / 重跑本 run 的离线推理，作业跑完自动刷新三份结果。侧栏「分析」页上线（离线作业队列与历史，替代旧 admin 离线 tab 的作业表）。
无后端改动。

## 变更背景

- **现状 / 痛点**（旧 admin 离线 tab）：
  - 手输 task_id / step_id；选中后还要点「加载」；只有提交前已加载同一 step，跑完才会自动刷新。
  - 违规只在侧栏列表里，没画到时间轴上；分割泳道与概率曲线靠固定 72px y 轴宽度对齐。
  - 动作类别颜色、中文名写死在前端。
- **触发来源**：控制台改造提案 [20261025_ADMIN_CONSOLE_REDESIGN_PROPOSAL.md](20261025_ADMIN_CONSOLE_REDESIGN_PROPOSAL.md) 第 4 批；人已定：侧栏叫「分析」、离线页只看不提交（后期任务结束自动跑）、类别与违规文字原样显示后端的值。
- **承接**：第 2 批时间轴泳道接口与事件面板、第 1 批全站离线作业轮询（[20261025_CONSOLE_SHELL_TASKS.md](20261025_CONSOLE_SHELL_TASKS.md)）。

## 方案详情

### 全景

```text
进入 run（step 有离线模型时）─▶ 同一 run_id、track=raw 并发取三份：
    POST /ai/temporal                         → 分割段泳道
    POST /lab-f3m8/label-probs                → 概率泳道（默认折叠）；labels[] 定类别顺序与配色
    GET  /admin-f3m8/offline/alarms/{t}/{s}   → 离线违规（过渡期端点）→ 并进事件
「运行 / 重跑离线推理」─▶ POST /admin-f3m8/offline/jobs（带 run_id）─▶ 全站作业轮询（3s）
    本 run 作业 queued/running → completed ─▶ 重取三份结果，分割泳道闪一下
    任意作业结束 ─▶ 全站 toast（带「查看结果」）；分析作业页对应行高亮
```

| 部件 | 落在哪 | 详见 |
|------|--------|------|
| 三份结果、作业提交、两条泳道 | `app/static/console/pages/run-offline.js` `useOffline` | §1 |
| 面板、事件合并 | `app/static/console/pages/run.js` | §2 |
| 作业结束提示、状态显示名 | `app/static/console/api/jobs.js` | §3 |
| 分析作业页 | `app/static/console/pages/offline.js` | §4 |

### 1. `useOffline`

- 只对 `stages[].has_offline_model` 为 true 的 step 取结果；否则泳道显示「{别名} 没有离线模型」。
- 类别顺序：有逐帧概率时取其 `labels[]`，否则按分割段出现顺序；颜色按这个顺序从调色板取（`core/levels.js` `labelColor`），不按类名写死。
- 泳道空状态按作业状态说明原因：排队中 / 运行中 / 失败（带 `message`）/ 未跑离线推理。
- 「规则未核对」与「核对过没有违规」分开显示（`checked`）。

### 2. 事件 = 平台告警 + 离线违规

两种来源经 `adapters.js` 归一成同一种行（类型、级别、文案原样取后端字段），按时刻排序，整段判定的违规（无时刻）排最后、不可跳转，并在事件泳道右端计数。离线违规的读取只出现在 `endpoints.offlineAlarms` + `adaptViolation` 两处，告警入库后改这两处。

### 3. 作业结束提示

全站作业轮询比较前后两轮状态，排队 / 运行 → 结束时弹 toast（「查看结果」跳该 run 的离线分析面板）并给该行 2.5 秒高亮；首轮只记录不提示。作业状态是离线作业服务的系统枚举，显示名在 `jobs.js` 一处映射，未知值原样显示。

### 4. 分析作业页

全部 / 运行中 / 排队 / 已完成 / 失败 五档筛选（`?status=` 进 URL）；列：任务、step 别名、run、状态、模型（`producer`）、段数、违规数、耗时、提交时间、说明；行点击进 `#/run/{t}/{s}/{run}?panel=offline`。不提供提交入口。

### 保留项（不改动）

- 后端零改动；旧 admin 离线 tab 照常可用，第 5 批删除。

## 变更效果

| 维度 | 变更前（旧 admin 离线 tab） | 变更后 |
|------|------|------|
| 选 run | 手输 id / 选表行 + 点「加载」 | 任务总览点芯片，或分析作业页点行 |

| 违规 | 侧栏列表 | 时间轴标记 + 事件面板，与平台告警同一列表 |
| 类别配色 / 名字 | 前端写死 | 取后端 `labels[]` 顺序，名字原样 |
