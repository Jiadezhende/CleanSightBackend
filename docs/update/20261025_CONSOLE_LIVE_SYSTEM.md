## 概述

控制台补齐最后两页：实时监控（在线 run 列表 + 聚焦一路的推理画面、近 10s 信号、告警流，告警可「回放此刻」）与系统运维（推理延迟按模型分线、核心计数器、健康监控、各路队列深度、延迟探测、LS 配置、任务清单来源）。工作台新增 `at=`（墙钟）入参。
无后端改动。旧 admin / lab 页在下一份记录里删除。

## 变更背景

- **现状 / 痛点**（旧 admin 页）：
  - 实时画面用 `client_id`（点位跟随）连 WS，同点位换了新 run 会悄悄切过去，告警游标不重置而串号；实时告警不能跳回放。
  - 延迟趋势把所有模型的分位数取平均；`/health/monitor/*` 没有页面；任务来源开关藏在 lab 的 LS 设置弹窗里，语义不清。
- **触发来源**：控制台改造提案 [20261025_ADMIN_CONSOLE_REDESIGN_PROPOSAL.md](20261025_ADMIN_CONSOLE_REDESIGN_PROPOSAL.md) 第 5 批；人已定：实时页不放积压曲线（队列深度看运维页当前值）、任务清单来源单独一块并讲清两档语义、指标与字段名原样显示后端的键。
- **承接**：第 1–4 批（外壳 / 出网层、回放工作台、送标、离线分析）。

## 方案详情

### 全景

```text
#/live/{task}?
  GET /task/live（3s）→ 在线 run（task_id / step_id / source_ip / run_id）
  聚焦一路：WS /ai/video?task_id=…（锁定这次 run）→ <img>；收到 idle → 「run 已结束 · 打开回放」
            GET /task/message/{task}?since_seq=max_seq（1Hz）→ signals_10s 的键原样 + 告警增量（最新在上，留 50 条）
  「回放此刻」→ #/run/{task}/{step}/{run_id}?panel=review&at=<告警墙钟 ms>
                 工作台按 raw 清单把 at 换算成媒体刻度（落进空洞吸附到下一段段首），改写成 t=
#/system
  /admin-f3m8/metrics/json（5s）→ 延迟按模型分线（p50/p95/p99 切换，页面不可见期间曲线断开）+ 三个计数器族
  /health/status（5s）、/health/monitor/config（一次）、/admin-f3m8/overview（3s，各路队列深度当前值）
  延迟探测：对选定的宽松档端点并发 GET，出分位数与直方图
  LS 配置 / 任务清单来源：PUT /lab-f3m8/config（来源卡下方「当前生效」取 /lab-f3m8/tasks 响应的 source）
```

| 部件 | 落在哪 |
|------|--------|
| 实时监控 | `app/static/console/pages/live.js` |
| 系统运维 | `app/static/console/pages/system.js` |
| 工作台 `at=` | `app/static/console/pages/run.js` `startOf` |
| 页面注册、删占位页 | `app/static/console/app.js`；删 `pages/pending.js` |

### 要点

- **只有聚焦的一路连 WS、拉信号与告警**：每帧约 55KB；`/task/message` 每路 1Hz，多路同时拉在 15 路规模下会逼近宽松档配额（600 次 / 60s）。所以左侧列表不显示每路信号灯。
- **画面停滞**：WS 没有心跳，末帧超过 3 秒没更新就在画面角上提示。
- **`at=` 而不是在实时页算 `t`**：实时页只知道告警的墙钟，媒体刻度要清单才能换算，放在已经拿到清单的工作台做。运行中的 run 清单偏短，晚于清单末尾的时刻贴到末尾。
- **LS 配置与任务来源分开保存**：PUT 是整体覆盖 url / project；LS 卡保存时 `task_source` 传 null（不改），来源卡保存时把当前 url / project 一并回传。

| 任务来源开关 | 藏在 LS 弹窗，语义不清 | 单独一块，两档说明 + 当前实际生效 |
